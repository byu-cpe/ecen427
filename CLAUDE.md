# ECEN 427 Course Website

This is a Jekyll site (deployed from GitHub: byu-cpe/ecen427). It is public.

- Build to verify changes: `make build`
- Commit and push to publish.
- Do not commit or push content changes on your own; the instructor prefers to
  review and push changes personally.
- **Never modify the git index.** No `git add`, `git reset`, `git restore
  --staged`, `git stash`, or `git mv`. The instructor stages files himself as he
  reviews; make edits in the working tree and stop. Read-only git is fine.

## Course workflows live in the solutions repo

Everything about running the course with Claude - the `learning-suite` skill and
its scripts, publishing lecture slides, creating quizzes, moving due dates, the
schedule pull - lives in the private solutions repo at `../solns` (its
`CLAUDE.md` and `.claude/skills/learning-suite/`). Run those tasks from there;
the scripts expect this website checkout as a sibling at `../website`.

Consequences for edits made here:

- `_data/schedule.yml` is generated by `../solns/.claude/skills/learning-suite/
  scripts/pull_schedule.py`; do not hand-edit it. Slide, reading and study links
  belong in the hand-maintained overlay `_data/schedule_links.yml`.
- Quizzes and their answer keys never go in this repo.
- Anything sensitive stays out of this repo; put it in `../solns`.
